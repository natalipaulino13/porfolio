Videoclub

Aplicación desarrollada en Java para gestionar un videoclub mediante programación orientada a objetos e interfaz gráfica.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto consiste en desarrollar una aplicación para gestionar diferentes elementos relacionados con un videoclub.

Para su desarrollo se utilizan clases, objetos y diferentes conceptos de programación orientada a objetos, junto con una interfaz gráfica realizada con Java Swing.

Elementos principales

Películas

Gestión de las películas disponibles dentro del videoclub mediante objetos y clases.

Categorías

Organización de las películas mediante diferentes categorías.

Interfaz gráfica

Uso de Java Swing para crear una interfaz gráfica que permite interactuar con la aplicación.

Programación Orientada a Objetos

Clases y objetos

Organización de la aplicación mediante clases y objetos que representan los elementos del videoclub.

Encapsulamiento

Uso de atributos y métodos para organizar y controlar la información de cada objeto.

Métodos

Implementación de diferentes métodos para trabajar con los datos y funcionalidades de la aplicación.

Conceptos utilizados

Java Programación Orientada a Objetos Clases y objetos Constructores Encapsulamiento Getters y setters Métodos Java Swing Interfaz gráfica

Resultado

La práctica permite aplicar los conocimientos de Java y programación orientada a objetos mediante una aplicación con interfaz gráfica para la gestión de un videoclub.
