Supermercado

Aplicación desarrollada en Java para gestionar diferentes funcionalidades de un supermercado mediante programación orientada a objetos.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto está desarrollado en Java y permite trabajar con diferentes elementos relacionados con la gestión de un supermercado.

Para su desarrollo se utilizan conceptos de programación orientada a objetos y una interfaz gráfica mediante Java Swing.

Características

Gestión

Organización y gestión de los diferentes elementos utilizados en la aplicación.

Java Swing

Interfaz gráfica desarrollada mediante componentes de Java Swing.

Programación Orientada a Objetos

Uso de clases, objetos, atributos, métodos y encapsulamiento.

Conceptos utilizados

Java POO Clases y objetos Constructores Encapsulamiento Getters y setters Métodos Java Swing Interfaz gráfica

Resultado

La práctica permite aplicar los conocimientos adquiridos en Java y programación orientada a objetos mediante una aplicación con interfaz gráfica.
