Gestión de Alumnos

Aplicación desarrollada en Java para gestionar un censo de alumnos y un registro de partes utilizando diferentes colecciones de Java.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto consiste en desarrollar una aplicación para gestionar un censo de alumnos y un registro de partes.

Para ello se utilizan diferentes colecciones de Java, concretamente un ArrayList para almacenar los partes registrados y un HashSet para mantener el censo de alumnos sin duplicados.

Gestión del censo

Mostrar censo

Permite mostrar todos los alumnos que forman parte actualmente del censo.

Añadir alumno

Permite introducir nuevos alumnos en el censo, evitando que existan alumnos duplicados.

Eliminar alumno

Permite eliminar un alumno del censo mediante su ID.

Buscar alumno

Permite buscar los datos de un alumno utilizando su ID.

Registro de partes

El programa mantiene un registro de partes asociados a los alumnos mediante un ArrayList.

Añadir parte

Permite poner un parte a un alumno buscándolo mediante su ID.

Mostrar partes

Permite mostrar todos los partes registrados actualmente.

Número de partes

Permite consultar el número total de partes registrados.

Partes por alumno

Permite buscar un alumno mediante su ID y mostrar cuántos partes tiene registrados.

ArrayList

El proyecto utiliza un ArrayList<Alumno> para almacenar los partes registrados.

Esta colección permite almacenar elementos repetidos, por lo que un mismo alumno puede aparecer varias veces si tiene varios partes.

La lista utilizada en el programa es:

partes

ArrayList<Alumno> encargado de almacenar los partes registrados.

HashSet

El HashSet se utiliza para almacenar los alumnos que forman parte del censo.

Esta colección no permite alumnos duplicados. Para determinar si dos alumnos son iguales se utilizan los métodos equals() y hashCode().

censo

Set<Alumno> encargado de mantener los alumnos del censo sin duplicados.

equals()

Compara dos alumnos utilizando su ID para determinar si son iguales.

hashCode()

Genera el código hash de cada alumno utilizando su ID.

Clase Alumno

La clase Alumno representa a cada alumno almacenado en el censo y en el registro de partes.

id

Identificador utilizado para identificar a cada alumno y comprobar si dos objetos son iguales.

nombre

Nombre del alumno.

curso

Curso en el que se encuentra matriculado el alumno.

Métodos

Incluye getters, setters, toString(), equals() y hashCode().

Menú de la aplicación

1. Mostrar censo

Muestra todos los alumnos que pertenecen al censo.

2. Mostrar partes

Muestra el registro de partes almacenados.

3. Añadir alumno

Permite añadir un nuevo alumno al censo.

4. Eliminar alumno

Permite eliminar un alumno del censo mediante su ID.

5. Poner parte

Permite añadir un parte a un alumno buscándolo mediante su ID.

6. Número de alumnos

Muestra el número de alumnos que forman parte del censo.

7. Número de partes

Muestra el número total de partes registrados.

8. Buscar alumno

Busca los datos de un alumno mediante su ID y muestra cuántos partes tiene.

9. Salir

Finaliza la ejecución del programa.

Eliminación de alumnos

Cuando se elimina un alumno del censo mediante su ID, también se eliminan sus partes registradas.

De esta forma, el registro de partes se mantiene relacionado con los alumnos que continúan formando parte del censo.

Clases principales

Alumno.java

Clase que representa los datos de cada alumno. Contiene ID, nombre y curso, además de los métodos necesarios para comparar y mostrar los objetos.

Main.java

Clase principal encargada de gestionar el menú, el censo de alumnos, el registro de partes y las operaciones realizadas sobre las colecciones.

Resultado

La práctica permite gestionar un censo de alumnos y un registro de partes utilizando diferentes colecciones de Java.

El uso de HashSet permite mantener el censo sin alumnos duplicados, mientras que ArrayList permite almacenar los partes registrados, incluso cuando un mismo alumno tiene varios.
