Refugio de Animales

Aplicación desarrollada en Java para gestionar diferentes tipos de animales mediante programación orientada a objetos, herencia y polimorfismo.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto trabaja con diferentes tipos de animales utilizando clases y programación orientada a objetos.

Se utiliza la herencia para crear diferentes clases de animales a partir de una clase común, permitiendo reutilizar atributos y métodos y definir comportamientos específicos.

Animales trabajados

Canario

Clase que representa un canario y sus características y comportamientos específicos.

Gato

Clase especializada que hereda las características comunes de los animales.

Perro

Clase especializada que representa un perro dentro de la aplicación.

Programación Orientada a Objetos

Herencia

Permite crear clases específicas a partir de una clase base, reutilizando sus características.

Polimorfismo

Permite que diferentes tipos de animales puedan comportarse de forma específica mediante métodos propios.

Encapsulamiento

Los atributos y métodos se organizan dentro de las clases para controlar el acceso a la información.

Conceptos utilizados

Java POO Clases y objetos Herencia Polimorfismo Encapsulamiento Constructores Métodos Getters y setters

Resultado

La práctica permite aplicar los principales conceptos de la programación orientada a objetos mediante la creación de diferentes tipos de animales y sus comportamientos.
