Figuras Geométricas

Práctica desarrollada en Java para trabajar con diferentes figuras geométricas mediante programación orientada a objetos.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El programa permite crear y gestionar diferentes figuras geométricas utilizando clases y programación orientada a objetos.

Se trabajan tres tipos de figuras: esferas, cilindros y ortoedros.

Figuras trabajadas

Esfera

Se calculan la superficie y el volumen de la esfera utilizando su radio.

Cilindro

Se calculan la superficie y el volumen utilizando el radio y la altura.

Ortoedro

Se calculan la superficie y el volumen a partir de su ancho, altura y largo.

Funcionamiento

Las figuras se crean utilizando diferentes tamaños: pequeña, mediana y grande.

A cada figura se le asigna aleatoriamente un color entre azul y verde. Posteriormente se calculan su superficie y volumen.

Los resultados se muestran por pantalla y se redondean a dos decimales.

Conceptos utilizados

Programación Orientada a Objetos Clases y objetos Constructores Encapsulamiento Getters y setters Métodos Random Math.PI Cálculos matemáticos Redondeo

Resultado

El programa muestra información de cada figura, incluyendo su tamaño, color, superficie y volumen.
