Alquiler de Coches

Aplicación desarrollada en Java para gestionar un sistema de alquiler de coches utilizando programación orientada a objetos, colecciones ArrayList y clases Comparator.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto consiste en desarrollar una aplicación para gestionar un sistema de alquiler de coches utilizando programación orientada a objetos y colecciones.

La aplicación permite gestionar coches disponibles y alquilados, introducir nuevos vehículos, realizar alquileres y devoluciones, avanzar los días de alquiler y consultar diferentes listados ordenados.

Clases principales

Coche

Representa los vehículos de la aplicación y contiene información como matrícula, marca, modelo, potencia y días alquilado.

Main

Contiene el menú principal y controla las diferentes operaciones de gestión de los coches.

OrdenadoMarca

Implementa Comparator para ordenar los coches utilizando su marca sin distinguir entre mayúsculas y minúsculas.

OrdenadoPotencia

Implementa Comparator para ordenar los coches según su potencia de menor a mayor.

Gestión de colecciones

El proyecto utiliza colecciones de Java para almacenar y gestionar los diferentes coches durante la ejecución.

Se utilizan principalmente objetos ArrayList<Coche> para trabajar con listas dinámicas de vehículos.

El programa utiliza tres listas principales: disponibles, alquilados y totales.

Estas colecciones permiten añadir, eliminar, consultar y ordenar los coches según diferentes criterios.

Funcionalidades

Gestión de coches

Permite consultar los coches disponibles y los que se encuentran actualmente alquilados.

Nuevo coche

Permite introducir un nuevo vehículo indicando matrícula, marca, modelo y potencia.

Alquiler y devolución

Permite alquilar coches disponibles y devolver vehículos alquilados calculando el precio según los días de alquiler.

Pasar día

Permite avanzar el día del sistema y aumentar automáticamente los días alquilados de los coches que están en alquiler.

Programación Orientada a Objetos

El proyecto está estructurado mediante diferentes clases que representan los elementos principales de la aplicación.

La clase Coche encapsula los datos de cada vehículo mediante atributos privados y métodos getters y setters para acceder y modificar su información.

Se utilizan conceptos fundamentales de la programación orientada a objetos como clases, objetos, atributos, métodos, encapsulación, constructores y sobrescritura del método toString().

Ordenación de datos

Comparator

El proyecto utiliza diferentes clases que implementan Comparator<Coche> para definir cómo se deben ordenar los vehículos.

Por matrícula

La clase OrdenadoMatricula permite ordenar los coches utilizando su matrícula mediante compareToIgnoreCase().

Por marca

La clase OrdenadoMarca permite ordenar los coches alfabéticamente según su marca.

Por potencia

La clase OrdenadoPotencia permite ordenar los vehículos según su potencia utilizando Integer.compare().

Estructura del proyecto

Coche.java

Clase encargada de representar los vehículos, almacenando sus datos y proporcionando métodos para acceder y modificar su información.

Main.java

Clase principal encargada de ejecutar la aplicación, mostrar el menú y gestionar los alquileres, devoluciones y listados.

Comparadores

Las clases OrdenadoDia, OrdenadoMarca, OrdenadoMatricula y OrdenadoPotencia permiten ordenar los coches según diferentes criterios.

Resultado

La práctica permite aplicar los conocimientos de Java y programación orientada a objetos mediante una aplicación basada en la gestión de un sistema de alquiler de coches.

Además, permite trabajar con colecciones ArrayList, gestión de objetos, cambio de estado de los vehículos, cálculo del precio del alquiler y ordenación mediante diferentes clases Comparator.
