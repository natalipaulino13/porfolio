Biblioteca

Aplicación desarrollada en Java para gestionar una biblioteca utilizando JDBC y SQLite, permitiendo realizar operaciones CRUD, búsquedas, filtros y ordenación de libros.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto consiste en desarrollar una aplicación de gestión de una biblioteca utilizando Java, JDBC y SQLite.

La aplicación permite administrar los libros almacenados en una base de datos mediante operaciones de creación, consulta, actualización y eliminación.

Base de datos

La aplicación utiliza una base de datos SQLite llamada biblioteca.db.

La tabla principal es libros y contiene información sobre los libros almacenados.

id

Identificador único utilizado para identificar cada libro.

titulo

Título del libro almacenado en la biblioteca.

autor

Autor correspondiente al libro registrado.

anio

Año de publicación del libro.

genero

Género literario al que pertenece el libro.

disponible

Indica si el libro se encuentra disponible mediante los valores 1 o 0.

La tabla libros se crea automáticamente si no existe en la base de datos.

Gestión de libros

Añadir libro

Permite introducir título, autor, año, género y disponibilidad. También comprueba que no exista otro libro con el mismo título, autor y año.

Listar libros

Permite mostrar todos los libros almacenados actualmente en la base de datos.

Buscar libro

Permite buscar un libro mediante su ID, título o autor utilizando consultas parametrizadas.

Actualizar libro

Permite modificar los datos de un libro mediante su ID. Los campos que se dejan vacíos mantienen su valor anterior.

Eliminar libro

Permite eliminar un libro mediante su ID después de solicitar confirmación.

Libros disponibles

Muestra únicamente los libros que tienen marcada su disponibilidad.

Búsqueda avanzada

Permite realizar búsquedas utilizando diferentes criterios como autor, género y disponibilidad.

Ordenar libros

Permite ordenar los libros por título, autor o año de publicación.

Conexión con SQLite mediante JDBC

La aplicación utiliza JDBC para establecer la conexión entre Java y la base de datos SQLite.

Para trabajar con la base de datos se utilizan diferentes elementos de JDBC para crear conexiones, ejecutar consultas y recuperar los resultados.

Connection

Representa la conexión establecida con la base de datos SQLite.

DriverManager

Se utiliza para establecer la conexión con la base de datos.

PreparedStatement

Permite ejecutar consultas parametrizadas para realizar búsquedas y operaciones de forma segura.

ResultSet

Permite recorrer y obtener los resultados de las consultas realizadas.

Operaciones CRUD

El proyecto aplica las principales operaciones CRUD sobre la tabla libros.

CREATE · INSERT

Permite introducir nuevos libros en la base de datos.

READ · SELECT

Permite consultar, listar y buscar los libros almacenados.

UPDATE

Permite actualizar la información de un libro existente.

DELETE

Permite eliminar libros de la base de datos.

Menú de la aplicación

1. Añadir libro

Permite registrar un nuevo libro en la biblioteca.

2. Listar todos los libros

Muestra todos los libros almacenados.

3. Buscar libro

Permite buscar libros por ID, título o autor.

4. Actualizar libro

Permite modificar los datos de un libro existente.

5. Eliminar libro

Permite eliminar un libro mediante su ID.

6. Libros disponibles

Muestra los libros que están disponibles.

7. Búsqueda avanzada

Permite buscar utilizando autor, género y disponibilidad.

8. Libros ordenados

Permite ordenar los libros por título, autor o año.

0. Salir

Finaliza la ejecución de la aplicación.

Validaciones

La aplicación incorpora diferentes comprobaciones para controlar los datos introducidos por el usuario.

Año de publicación

El año debe encontrarse entre 1500 y 2026.

Disponibilidad

La disponibilidad se introduce mediante los valores 1 para disponible y 0 para no disponible.

Libros duplicados

Se evita registrar un libro que tenga el mismo título, autor y año.

Clase principal

Main.java

Clase principal encargada de mostrar el menú, gestionar las opciones seleccionadas y realizar las operaciones sobre la base de datos SQLite.

Además, incorpora búsquedas, filtros, ordenación y validaciones para controlar los datos introducidos.
