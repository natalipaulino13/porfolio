Biblioteca

Aplicación desarrollada en Java para gestionar una biblioteca utilizando JDBC y SQLite, permitiendo realizar operaciones CRUD, búsquedas, filtros y ordenación de libros.

01 · DESCRIPCIÓN

Sobre la práctica

Esta práctica consiste en desarrollar una aplicación de gestión de una biblioteca utilizando Java, JDBC y SQLite.

La aplicación permite administrar los libros almacenados en una base de datos mediante diferentes operaciones de consulta, modificación, eliminación, búsqueda y ordenación.

Ver proyecto en GitHub →

02 · BASE DE DATOS

Base de datos

La aplicación utiliza una base de datos SQLite llamada biblioteca.db.

La tabla principal es libros y contiene los siguientes campos:

id — Identificador del libro

titulo — Título del libro

autor — Autor del libro

anio — Año de publicación

genero — Género literario

disponible — Disponibilidad del libro

La tabla se crea automáticamente si no existe.

03 · JAVA

Clase principal

La aplicación utiliza una clase principal que muestra un menú por consola para gestionar los libros de la biblioteca.

1.- Añadir libro

2.- Listar todos los libros

3.- Buscar libro

4.- Actualizar libro

5.- Eliminar libro

6.- Listar libros disponibles

7.- Búsqueda avanzada

8.- Listar libros ordenados

0.- Salir

04 · FUNCIONALIDADES

Funcionalidades

➕ Añadir libro

Permite introducir título, autor, año, género y disponibilidad. También evita duplicados.

📋 Listar libros

Muestra todos los libros almacenados en la base de datos.

🔎 Buscar libro

Permite buscar libros por ID, título o autor mediante consultas parametrizadas.

✏️ Actualizar

Permite modificar los datos de un libro utilizando su ID.

🗑️ Eliminar

Permite eliminar un libro de la base de datos solicitando confirmación.

📚 Disponibles

Muestra únicamente los libros que están disponibles.

🔍 Búsqueda avanzada

Permite filtrar los libros por autor, género y disponibilidad.

↕️ Ordenación

Permite ordenar los libros por título, autor o año.

Resultado

El resultado es una aplicación de consola capaz de gestionar una biblioteca completa mediante una base de datos SQLite, aplicando Java, SQL y JDBC.

Como ejemplo, se puede registrar el libro El Quijote, de Miguel de Cervantes, publicado en 1605, perteneciente al género Novela y disponible.
