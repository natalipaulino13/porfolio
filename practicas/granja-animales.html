Granja de Animales

Aplicación desarrollada en Java para representar diferentes animales de una granja utilizando programación orientada a objetos, herencia, clases abstractas e interfaces.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto consiste en crear una pequeña estructura de animales de una granja utilizando programación orientada a objetos.

Se trabajan conceptos como clases abstractas, herencia, interfaces, encapsulamiento y sobrescritura de métodos.

Animales de la granja

🐷 Cerdo

Hereda de la clase abstracta Animal y añade el atributo específico color.

Implementa el método tipoAnimal().

🐑 Oveja

Hereda de la clase abstracta Animal y añade el atributo tipoDePelo.

Implementa el método tipoAnimal().

🐄 Vaca

Hereda de Animal e implementa además la interfaz LecheProducida.

Puede calcular aleatoriamente la cantidad de leche producida mediante el método ordenyar().

Clase abstracta Animal

La clase Animal actúa como clase base para los diferentes animales de la granja.

Contiene características comunes como el nombre, el peso y la edad.

También define el método abstracto tipoAnimal(), que cada animal debe implementar según su propio tipo.

Herencia

Animal → Cerdo

El cerdo hereda los atributos y métodos comunes definidos en Animal y añade su propio atributo relacionado con el color.

Animal → Oveja

La oveja hereda las características comunes de Animal y añade información sobre su tipo de pelo.

Animal → Vaca

La vaca hereda de Animal y añade características propias relacionadas con la producción de leche.

Interfaz LecheProducida

La interfaz LecheProducida define el contrato para aquellos animales capaces de producir leche.

Contiene el método ordenyar(), encargado de devolver la cantidad de leche producida.

La clase Vaca implementa esta interfaz y genera una cantidad aleatoria de leche entre 3 y 8 litros, redondeada a un decimal.

Funcionamiento

Características comunes

Todos los animales comparten nombre, peso y edad, definidos en la clase abstracta Animal.

Tipos de animal

Cada clase implementa el método tipoAnimal() para definir el tipo correspondiente.

Producción de leche

Las vacas pueden generar aleatoriamente una cantidad de leche utilizando el método ordenyar().

Estructura del proyecto

Animal.java

Clase abstracta que contiene las características comunes de los animales.

Cerdo.java

Clase que hereda de Animal y representa al cerdo.

Oveja.java

Clase que hereda de Animal y representa a la oveja.

Vaca.java

Clase que hereda de Animal e implementa LecheProducida.

LecheProducida.java

Interfaz que define el método para calcular la producción de leche.

Resultado

La práctica permite trabajar de forma práctica con programación orientada a objetos mediante una estructura basada en una clase abstracta y diferentes clases derivadas.

Además, permite aplicar herencia, interfaces, sobrescritura de métodos y generación de valores aleatorios en Java.
