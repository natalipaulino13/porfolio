Juego del Bombo

Aplicación desarrollada en Java que simula un juego de bingo mediante clases, objetos y programación orientada a objetos.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto consiste en desarrollar la lógica necesaria para simular un juego del bombo utilizando Java.

Para organizar el funcionamiento del programa se utilizan diferentes clases y objetos, aplicando conceptos de programación orientada a objetos.

Elementos principales

Bombo

Se encarga de gestionar la lógica relacionada con la extracción de números durante el juego.

Jugador

Representa a los participantes del juego y la información necesaria para su funcionamiento.

Main

Clase principal desde la que se inicia y controla la ejecución del programa.

Funcionamiento

El programa utiliza la lógica del juego para trabajar con los números del bombo y gestionar la participación de los jugadores.

De esta forma se ponen en práctica estructuras de control, métodos, objetos y diferentes conceptos fundamentales de Java.

Conceptos utilizados

Java Programación Orientada a Objetos Clases y objetos Constructores Encapsulamiento Métodos Arrays Lógica de programación

Resultado

La práctica permite desarrollar la lógica de un juego utilizando Java y aplicar los conocimientos adquiridos sobre programación orientada a objetos.
