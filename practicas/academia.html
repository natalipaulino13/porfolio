Gestión de Personal

Práctica desarrollada en Java para gestionar el personal de una organización mediante programación orientada a objetos, herencia, ficheros de texto y Java Swing.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El programa permite gestionar el personal de una organización utilizando programación orientada a objetos, herencia, polimorfismo y ficheros de texto.

Se trabajan dos tipos de trabajadores: profesores y administrativos.

Tipos de personal

Persona

Clase abstracta que contiene los datos comunes de profesores y administrativos, como DNI, nombre, apellidos, edad, sexo y salario.

Profesor

Clase que hereda de Persona y añade la asignatura que imparte y el número de horas lectivas.

Administrativo

Clase que hereda de Persona y añade el departamento donde trabaja y sus años de antigüedad.

Funcionamiento

Al iniciar el programa se leen los datos almacenados en personal.txt y se crean los objetos correspondientes.

El programa permite mostrar todo el personal, mostrar únicamente profesores o administrativos y buscar personas mediante su DNI.

También permite añadir y eliminar profesores y administrativos mediante ventanas gráficas desarrolladas con Java Swing.

Gestión de ficheros

Los datos de los trabajadores se almacenan en un fichero de texto llamado personal.txt.

Cada trabajador se almacena en una línea y los diferentes datos están separados mediante el carácter ;.

Para leer y guardar la información se utilizan clases como File, FileReader, FileWriter, BufferedReader y BufferedWriter.

Interfaz gráfica

Profesores

Ventana gráfica para añadir y eliminar profesores. Se solicitan datos como DNI, nombre, asignatura, salario y horas lectivas.

Administrativos

Ventana gráfica para añadir y eliminar administrativos. Se solicitan datos como DNI, nombre, departamento, salario y antigüedad.

Validación

Antes de añadir una persona se comprueba que no exista otro trabajador con el mismo DNI y se validan los valores numéricos introducidos.

Conceptos utilizados

Programación Orientada a Objetos Herencia Polimorfismo Clase abstracta Encapsulamiento Clases y objetos ArrayList instanceof Ficheros de texto File FileReader FileWriter BufferedReader BufferedWriter Scanner IOException Java Swing JFrame JPanel JTextField JButton JRadioButton JOptionPane

Resultado

El programa permite gestionar profesores y administrativos, consultar el personal almacenado, buscar trabajadores por DNI y guardar los datos en un fichero de texto.

La práctica combina programación orientada a objetos, herencia, polimorfismo, gestión de ficheros e interfaces gráficas mediante Java Swing.
