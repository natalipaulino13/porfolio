Agenda de Contactos

Aplicación desarrollada en Java para gestionar una agenda de contactos utilizando ArrayList y serialización de objetos mediante un fichero binario.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto consiste en desarrollar una agenda de contactos utilizando un ArrayList para mantener los datos en memoria y serialización de objetos para guardarlos en un fichero binario.

Cada contacto contiene información como DNI, nombre, apellido, teléfono y email.

Gestión de contactos

Añadir contactos

Permite introducir un nuevo contacto indicando DNI, nombre, apellido, teléfono y email.

Listar contactos

Permite mostrar todos los contactos almacenados actualmente en memoria.

Eliminar contactos

Permite eliminar un contacto mediante la búsqueda de su DNI.

Actualizar fichero

Permite guardar en el fichero binario todos los contactos almacenados en memoria.

ArrayList

Los contactos se mantienen en memoria mediante un ArrayList<Contacto>.

Esta colección permite almacenar y gestionar dinámicamente los diferentes contactos de la agenda.

Antes de añadir un contacto se comprueba que no exista otro con el mismo DNI.

Serialización

El proyecto utiliza la serialización de objetos de Java para guardar el ArrayList completo en un fichero binario.

La clase Contacto implementa Serializable, permitiendo almacenar sus objetos directamente en el fichero.

Lectura

Se utilizan FileInputStream y ObjectInputStream para recuperar los contactos almacenados.

Escritura

Se utilizan FileOutputStream y ObjectOutputStream para guardar los contactos en el fichero.

contactos.bin

Es el fichero binario utilizado para conservar los contactos entre ejecuciones del programa.

Control de cambios

El programa utiliza una variable llamada cambios para controlar si existen modificaciones pendientes de guardar.

Cuando se añade o elimina un contacto se marcan cambios pendientes.

Si no existen cambios, el fichero no se actualiza. Al salir del programa, los cambios pendientes se guardan automáticamente antes de finalizar.

Menú de la aplicación

1. Listar contactos

Muestra los contactos que se encuentran actualmente en memoria.

2. Introducir contacto

Permite crear y añadir un nuevo contacto a la agenda.

3. Eliminar contacto

Busca un contacto mediante su DNI y permite eliminarlo.

4. Actualizar fichero

Guarda los contactos de memoria en contactos.bin.

5. Salir

Comprueba si existen cambios pendientes y los guarda antes de finalizar el programa.

Clases principales

Contacto.java

Clase que representa cada contacto de la agenda. Implementa Serializable para permitir su almacenamiento en el fichero binario.

Main.java

Clase principal encargada de gestionar el menú, el ArrayList de contactos y la lectura y escritura del fichero.

Resultado

Además, permite aplicar ArrayList y serialización de objetos para trabajar con ficheros binarios en Java.
