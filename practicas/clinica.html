Gestión de Pacientes

Aplicación desarrollada en Java para gestionar los pacientes de una clínica mediante JDBC y una base de datos SQLite.

Ver práctica en GitHub ↗

Sobre la práctica

Esta práctica pertenece al módulo de Programación del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto consiste en desarrollar una aplicación para gestionar una base de datos de pacientes de una clínica utilizando Java, JDBC y SQLite.

La aplicación permite almacenar y gestionar información como DNI, nombre, edad, número de móvil, peso y seguro médico.

Base de datos

SQLite

Los datos se almacenan en una base de datos SQLite llamada clinica.db.

Pacientes

La tabla pacientes contiene información personal y datos relacionados con el seguro médico.

DNI único

El DNI está definido como UNIQUE para evitar que existan dos pacientes con el mismo identificador.

Funcionalidades

La aplicación dispone de un menú desde el que se pueden realizar diferentes operaciones sobre los pacientes.

Añadir pacientes

Permite registrar nuevos pacientes introduciendo sus datos personales y la información del seguro médico.

Consultar pacientes

Permite listar todos los pacientes y realizar búsquedas mediante DNI o nombre.

Actualizar datos

Permite modificar el nombre, edad, móvil, peso y seguro médico de un paciente.

Eliminar pacientes

Permite eliminar pacientes mediante su DNI, solicitando confirmación antes de realizar la operación.

Filtros

Permite listar pacientes asegurados, mayores de edad y pacientes dentro de un determinado rango de peso.

Añadir móvil

Permite introducir un número de móvil cuando un paciente todavía no dispone de él.

Consultas SQL

El proyecto utiliza diferentes consultas SQL para trabajar con la información almacenada en la base de datos.

Se utilizan operaciones como INSERT, SELECT, UPDATE y DELETE para implementar las funcionalidades principales de la aplicación.

También se utilizan consultas con WHERE, LIKE y BETWEEN para realizar búsquedas y filtros sobre los pacientes.

JDBC

Connection

Se utiliza para establecer la conexión entre la aplicación Java y la base de datos SQLite.

PreparedStatement

Permite ejecutar consultas SQL parametrizadas para trabajar con los datos de forma segura.

ResultSet

Se utiliza para obtener y recorrer los resultados de las consultas realizadas a la base de datos.

Statement

Permite ejecutar determinadas instrucciones SQL desde la aplicación.

Conceptos utilizados

Java Programación Orientada a Objetos JDBC SQLite Bases de datos relacionales SQL CRUD PreparedStatement ResultSet Connection Statement Scanner SQLException Consultas parametrizadas Filtros Búsquedas

Estructura del proyecto

Main.java

Clase principal encargada de establecer la conexión, crear la tabla, mostrar el menú y gestionar las diferentes operaciones de la aplicación.

clinica.db

Base de datos SQLite donde se almacenan los registros de los pacientes.

Resultado

La práctica permite aplicar los conocimientos de Java y bases de datos para crear una aplicación capaz de gestionar información mediante operaciones CRUD y consultas SQL.

Además, permite trabajar con JDBC y SQLite, conectando una aplicación Java con una base de datos relacional.
