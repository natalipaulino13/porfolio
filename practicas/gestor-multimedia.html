Sobre la práctica

Gestor Multimedia es una aplicación desarrollada en Java utilizando los principios de la Programación Orientada a Objetos.

El proyecto permite trabajar con diferentes elementos multimedia y organizar la información mediante distintas clases.

Durante el desarrollo se aplican conceptos fundamentales de Java como clases, objetos, encapsulamiento, métodos y relaciones entre diferentes elementos del programa.

Tecnologías utilizadas

Java

Lenguaje principal utilizado para desarrollar la aplicación.

POO

Programación Orientada a Objetos mediante clases y objetos.

Clases

Organización del código mediante diferentes clases relacionadas entre sí.

Encapsulamiento

Gestión de atributos y métodos dentro de las diferentes clases.
